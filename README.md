A collection of interactive **3D games and physics-based simulations** developed in **Python (VPython)** and **Unity**, blending creative gameplay with scientific modeling.  

Each project showcases aspects of *simulation systems, applied AI logic, and real-time visualization*.

<img src="https://github.com/sabneet95/Game-Development/blob/main/Clue/gameboard.gif" width="853.3" height="480">


## 🕹️ Featured Projects

| Project | Description | Language / Engine |
|---------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------|-----------------|
| [**Clueless**](https://github.com/sabneet95/Game-Development/tree/main/Clue) | A 3D Unity adaptation of *Clue®*, featuring C# gameplay scripts and a Python–MySQL backend for multiplayer coordination. | Unity + Python |
| [**SpaceBall**](https://github.com/sabneet95/Game-Development/tree/main/Space) | A planetary basketball simulation blending orbital mechanics with gameplay physics, built in VPython. | Python (VPython) |
